# 📊 Bank Customer Churn Analysis

## 📌 Project Overview
This project analyzes customer churn behavior in a banking dataset to identify key factors driving customer attrition. The goal is to help the bank reduce churn and improve customer retention strategies using data-driven insights.

---

## 🎯 Business Problem
Customer churn leads to revenue loss. The objective was to:
- Identify high-risk customers
- Analyze churn patterns across demographics and behavior
- Provide actionable insights to improve retention

---

## 🛠 Tools Used
- Excel – Data Cleaning & Feature Engineering
- SQL Server – Data Analysis & KPI Calculation
- Power BI – Dashboard & Visualization

---

## 📊 Key KPIs
- Total Customers: 10,000
- Total Churned Customers: 2,037
- Churn Rate: 20.37%
- Active Customers: 5,151
- Average Balance (Churned): 91.04K

## 🔍 Key Insights
- Germany has the highest churn rate (~32%)
- Senior customers show highest churn (~44%)
- Customers with 3–4 products have highest churn risk
- Customers with poor credit score show higher churn (~22%)
- Inactive customers churn significantly more than active customers
- Overall churn rate is 20.37%

---

## 💡 Business Recommendations
- Focus retention campaigns on high-risk regions like Germany
- Improve engagement strategies for inactive customers
- Promote cross-selling to increase product usage
- Design loyalty programs for senior customers
- Monitor low credit score customers closely

---

## ⚙️ Project Workflow
1. Data Cleaning and preprocessing using Excel
2. Data analysis and KPI calculation using SQL Server
3. Dashboard development and visualization in Power BI
4. Business insights generation and interpretation
